# 畫面零件（library/scenes.js）

資料驅動的通用場景：在 project.json 寫 `{"fn": "L_xxx", "bars": 2, "energy": .6, "data": {...}}` 就能使用，不需要寫程式。所有場景都有橫式與直式版面，只用 `STYLE.c.*` 顏色，換任何風格包都能正常顯示。

**這是 Claude 內部的版面零件，不是給使用者挑的選單。** 分鏡時依每幕要講的事決定畫面：內容剛好是下表某一種時用零件（最快，版面已經在所有錨點風格、橫直式下驗證過）；這幕的重點是具體的畫面隱喻時寫自訂場景（見 api.md）。兩者可以在同一支片混用，判斷方式見 direction.md 第 6 節。

`data` 以外的欄位（`bars`、`energy`、`trans`）說明見 api.md 第 1 節。以 `_` 開頭的欄位（例如 `_hint`）會被忽略，可以用來寫備註。

## 目錄
| 場景 | 用途 | 建議小節 |
|---|---|---|
| L_title | 大字標題：開場、揭示、結論 | 2 |
| L_quote | 金句、洞察、感謝 | 2 |
| L_cards | 2–6 張卡片：特色、作品、團隊、資源 | 2–3 |
| L_steps | 2–6 個流程步驟 | 3–4 |
| L_timeline | 2–6 個時間節點 | 3 |
| L_numbers | 1–4 個關鍵數字 | 2 |
| L_bars | 2–8 列橫條圖 | 2 |
| L_line | 1–2 條折線趨勢 | 3 |
| L_compare | 左右（直式為上下）對比 | 3 |
| L_list | 2–6 條重點，逐拍出現 | 2 |
| L_kinetic | 逐拍大字（kinetic typography） | 2–4 |
| L_countdown | 倒數 | 2 |
| L_logo | 收尾字標 | 2（放在最後一幕） |
| L_cta | 行動呼籲按鈕 | 2 |
| L_look | 畫風背景與場景（資料驅動的開放構圖，10 種畫風） | 2–3，欄位見 looks.md |

元素數量超過上限的部分會被截掉；項目越多，每個項目出現的間隔越短，所以項目多時要加小節數。

---

### L_title
```json
{ "kicker": "小標（選填）", "lines": ["第一行", "第二行"], "sub": "副標（選填）", "align": "center" }
```
- `lines` 1–4 行，逐行在第 1、3、5 拍遮罩揭示；有多行時最後一行套強調色漸層。
- 字級依最長那一行自動縮放，所以每行長度相近最好看。
- `align` 可設 `"left"`，適合編輯風格。

### L_quote
```json
{ "quote": "金句內容", "by": "出處（選填）" }
```
橫式最多 3 行、直式最多 5 行，超過時自動縮字。60 字以內最好讀。

### L_cards
```json
{ "title": "標題", "sub": "副標", "items": [ { "title": "卡片標題", "desc": "一句說明", "tag": "選填，預設 01、02…" } ] }
```
- 橫式：5 張以內排一列，6 張排成 3×2；直式：4 張以內一欄，5–6 張兩欄。
- `desc` 放不下時自動截斷並加「…」，所以寫一句就好。
- 全部進場後每拍輪流高亮一張。

### L_steps
```json
{ "title": "標題", "sub": "副標", "steps": [ { "title": "步驟名", "desc": "說明（選填）" } ] }
```
節點依序點亮並有進度線。橫式水平排列，直式垂直排列。

### L_timeline
```json
{ "title": "標題", "events": [ { "when": "時間", "title": "事件", "desc": "說明（選填）" } ] }
```
與 L_steps 相同，但每個節點多一個 `when` 標籤；橫式時文字上下交錯排列，避免擠在一起。

### L_numbers
```json
{ "title": "標題（選填）", "items": [ { "value": 1200, "label": "說明", "note": "註記（選填）" } ] }
```
- `value` 可以是數字或字串：`1200`、`"98.5%"`、`"NT$ 3.2億"`、`"1,200+"`。程式會抓出其中的數字來滾動，前後文字保留，小數位與千分位跟隨原始寫法。
- 沒有數字的字串（例如 `"第一"`）改用打字效果。
- 只放 1 個數字時會特別大，適合數據故事開場。

### L_bars
```json
{ "title": "標題", "sub": "單位或來源", "unit": "%", "hi": 0, "items": [ { "label": "類別", "value": 42 } ] }
```
- 橫條圖（直式也好讀）。`hi` 是要強調的列索引；省略時自動強調最大值。
- `value` 必須是數字。`unit` 會加在數值後面。

### L_line
```json
{ "title": "標題", "sub": "單位或來源", "unit": "", "labels": ["1月", "2月"],
  "series": [ { "name": "系列名（選填）", "values": [12, 15] } ] }
```
- 1–2 條折線；也可以只給 `"values": [...]`。
- Y 軸自動取整數刻度並從 0 開始（有負值時往下延伸）。
- X 軸標籤過多時自動跳著顯示。

### L_compare
```json
{ "title": "標題", "left": { "title": "過去", "items": ["…"] }, "right": { "title": "現在", "items": ["…"] } }
```
左邊先出現（✕ 記號、次要色），約 40% 處右邊出現（勾號、強調色、發光），左邊同時變暗。每邊最多 5 條，每條一行。

### L_list
```json
{ "title": "標題", "sub": "副標", "items": ["重點一", "重點二"] }
```
逐拍出現，3 條以內用較大字級。每條最多兩行。

### L_kinetic
```json
{ "words": ["短句", "一拍", "一個"], "beats": 1, "invert": true }
```
- 一次只顯示一個字詞，放大衝進畫面。`beats` 是每個字詞佔幾拍；省略時依本幕長度平均分配（至少一拍）。
- `invert` 預設開啟：偶數個字詞會反白（強調色底、背景色字）。
- **字詞越短越有力**：4–8 個中文字最好。`words` 數量 × `beats` 應該剛好填滿本幕的拍數（一小節 4 拍）。

### L_countdown
```json
{ "from": 3, "then": "倒數後的字（選填）", "sub": "副標（選填）" }
```
有 `then` 時最後 4 拍留給它。倒數數字平均分配剩下的時間。

### L_logo
```json
{ "name": "名稱", "tagline": "標語（選填）", "mark": "ring" }
```
`mark`：`ring`（雙環旋轉）、`dot`（圓點）、`bars`（長條，適合數據主題）、`none`。名稱從第 3 拍開始逐字展開。

### L_cta
```json
{ "title": "行動呼籲", "action": "按鈕文字", "note": "網址或聯絡方式（選填）" }
```
按鈕在第 3 拍彈出並隨拍點微微放大。email 不要直接寫在 `note`，見 SKILL.md 的陷阱說明。

## 延伸場景庫

場景庫的函式也可以在自訂場景裡呼叫，例如先畫 `L_head()` 頁首再加自己的圖形：

```js
function sCustom(t, T, pulse, s) {
  const top = L_head(t, '標題', '副標');   // 回傳頁首下緣的 y
  // …在 top 到 SAFE.b 之間畫自己的內容
}
```

其他可用的輔助函式：`_gap(T, n)` 算出 n 個元素的出現間隔（對齊半拍）、`_fmtNum(p, value)` 數值滾動、`clampLines(s, maxW, size, n)` 限制行數。
