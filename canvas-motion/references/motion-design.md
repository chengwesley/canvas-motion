# 動態設計準則：出場順序、時長、緩動、編排

`craft.md` 講「動作要有重量與性格」，這份講「畫面上很多東西時，誰先動、動多久、用什麼緩動」。寫場景、排 `hero` 與 `sfx` 時參考；數字是起點，依片子的調性調整。

## 1. 先問三件事
1. **這個動作幫觀眾看懂什麼？** 說不出來就不要動，或改成背景的緩慢呼吸。
2. **這一刻誰是主角？** 一個畫面只有一個主角先出場、動作最大；其他元素依序跟上，不要整個畫面同時開演。
3. **哪一塊、什麼時候、怎麼動？** 寫進場景前用一句話講清楚，例如「切點後半拍，標題由下往上 30px 淡入；一拍後三張卡片由左到右每張間隔 0.08 秒彈入」。

## 2. 時長（秒）

影片比 UI 慢一點（觀眾沒有在操作，需要時間讀），下表已經換算成影片用的範圍。

| 元素 | 時長 |
|---|---|
| 小回饋（勾勾、數字跳一下） | .12–.2 |
| 按鈕、圖示、標籤 | .2–.35 |
| 卡片、截圖、角色進場 | .35–.6 |
| 整幕轉場 | .5–.8 |
| 戲劇性揭示（標誌、高光） | .8–1.5 |
| 背景呼吸、漂移 | 3–20（循環） |

- **距離越遠越久**：移動 1/10 畫面寬用 1 倍，半個畫面 1.5 倍，整個畫面 1.8–2 倍。
- **退場比進場快**：退場時長約為進場的 65–75%。
- **調性決定快慢**：活潑 0.7 倍、企業 1 倍、高級 1.4 倍、熱血 0.6 倍。

## 3. 緩動（對應 `E.*` 與 `spring`）

| 用途 | 緩動 |
|---|---|
| 進場 | `out`、`expo`（快進慢停） |
| 退場 | `in`（慢起快走） |
| 畫面內移動、鏡頭 | `io` |
| 循環（呼吸、漂浮） | `Math.sin` |
| 旋轉、進度條 | 線性 |
| 活潑的到位 | `back`、`spring(t, start, 2.2, .38)` |
| 很彈（慶祝、驚喜） | `spring(t, start, 2.2, .2)`、`elastic` |

- **空間移動不要用線性**，看起來像機器。
- **過衝的預算**：成功 5–10%、回饋 2–5%、慶祝 15–25%、錯誤與高級感 0%。
- **材質感**：硬物（金屬、玻璃）不過衝；紙與卡片 3–5%；橡膠 15–25%；煙與液體慢而不過衝。

## 4. 編排（多個元素時）

- **主角先行**：主角位移最大、緩動最搶眼；配角在每個維度都更小、更晚、更輕。
- **同一個方向進場**：一組元素從同一側或同一個源頭出來；方向混亂就是雜亂。
- **反向動作**：主角往右，背景往左 20–30%；主角放大，影子縮小變淡；主角上升，影子擴散。畫面才有重量與景深。
- **三分之一法則**：
  - 一段移動不超過畫面 1/3 不轉彎，要有中途的方向或速度變化。
  - 三個以上元素時，同時在動的不超過 1/3：第一個落定時第三個才開始。
- **錯開（stagger）**：每個間隔 .04–.1 秒，整組總長不超過 .6 秒；同一組用同一種緩動，只錯開開始時間；最後一個可以多一點過衝當句點。
- **順序**：清單由上到下、橫排由左到右、主視覺由中心向外、退場反向。
- **一幕的結構**：鋪陳 20–30%（元素進場）→ 動作 30–40%（主角、高光）→ 收尾 30–40%（落定、次要反應、呼吸）；收尾後留 .1–.2 秒靜止，再開始下一個動作。
- **景深**：前景移動 1 倍、中景 .5 倍、背景 .2 倍（`layer()`）。

## 5. 進場與退場的做法

| 做法 | 參數 | 適合 |
|---|---|---|
| 滑入 | 位移 20–40px（`MIN` 的 3–6%）＋淡入，`out` | 文字、清單、卡片 |
| 放大進場 | 從 85–95% 放大＋淡入；活潑可從 70% 加過衝 | 視窗、標籤、角色、圖示 |
| 遮罩揭示 | `reveal()` 由上而下、由左而右、由中心向外 | 大標、數字、截圖 |
| 組裝 | 部件從不同位置錯開進場，總長 .3–.6 秒 | 標誌、圖表、流程圖 |
| 轉移退場 | 朝目的地移動並縮小，`io` | 加入購物車、存進資料夾、送出 |

- 方向帶有意義：由下往上＝抵達、由右往左＝前進、由左往右＝返回、由上往下＝權威或下拉。
- 前一個元素退場的位置靠近下一個元素進場的位置，觀眾的視線才接得上；兩者重疊 .1–.15 秒。

## 6. 檢查（看縮圖與 motion.png 時一起問）

- 不用慢動作也看得懂；最重要的狀態改變不只靠淡入淡出（要有位移、縮放或顏色）。
- 主角、配角、背景三層分得出來；同一種事件整支片用同一種動法。
- 錯開的總長在 .6 秒內；進場比退場久；空間移動沒有線性緩動。
- 小東西（小於畫面 4%）不要做細緻動作，觀眾看不到。
- 全畫面閃光每秒不超過 3 次（光敏安全）。
