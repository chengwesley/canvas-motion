# 情境 → 決策

從使用者的需求與情境直接推出規格、敘事、節奏與風格。**能推斷就不問**；推斷結果寫進提案，讓使用者一次確認。

## 1. 讀出情境訊號

| 訊號 | 從哪裡讀 | 沒有時 |
|---|---|---|
| 目的 | 使用者的話、素材類型 | 依素材：數字多 → 告知；產品 → 說服；人與團隊 → 連結 |
| 觀眾 | 「給主管／客戶／新人／粉絲」 | 一般大眾 |
| 平台 | Reels、Shorts、簡報、官網、尾牙大螢幕 | 兩用（aspect: auto） |
| 調性 | 形容詞、品牌、場合 | 由目的 × 觀眾推（見「調性 → 節奏與風格」） |
| 素材 | 文件、網址、口述 | **唯一必問**，沒有素材不開工 |
| 構圖 | 使用者描述的主體、場景、遠近、動態 | **開放問**；沒想法時依素材提一個構圖讓他改 |

## 2. 平台 → 規格

| 平台 | aspect | 片長 | 備註 |
|---|---|---|---|
| IG Reels／Shorts／TikTok | 9:16 | 15–25 秒 | 前 2 秒要有鉤子；字級用直式大字 |
| 簡報開場、會議投影 | 16:9 | 20–40 秒 | 可以慢一點，留白多 |
| 官網、README、Demo | auto | 20–30 秒 | 匯出 GIF 時控制在 20 秒內 |
| 大螢幕活動（尾牙、發表會） | 16:9 | 30–60 秒 | energy 高、轉場大膽 |
| 內部公告、教學 | auto | 30–60 秒 | 清楚優先，一幕一重點 |

片長 → 小節：總秒數 × BPM / 240。例如 24 秒 @ 100 BPM = 10 小節，通常 4–6 幕。

## 3. 目的 → 敘事弧（細節見 narratives.md）

| 目的 | 敘事弧 | 高潮放 |
|---|---|---|
| 說服（產品、提案） | 痛點 → 轉折 → 怎麼做到 → 證據 → 行動 | 證據（數字或對比） |
| 告知（公告、上線） | 鉤子 → 是什麼 → 三個重點 → 怎麼開始 | 最重要的一個改變 |
| 數據故事 | 大數字 → 趨勢 → 拆解 → 洞察 | 洞察那一句 |
| 教學、流程 | 目標 → 步驟 → 注意 → 下一步 | 最關鍵的步驟 |
| 連結（人、團隊、歡迎） | 情緒開場 → 人事物 → 你會得到 → 一起 | 與觀眾自己有關的那一幕 |
| 慶祝、回顧 | 開場 → 里程碑 → 數字 → 感謝 | 感謝或最大的里程碑 |
| 氛圍（MV、片頭） | 鋪陳 → 累積 → 爆發 → 收 | 爆發（逐拍大字） |

## 4. 調性 → 節奏與風格

| 調性 | BPM | energy 曲線 | 轉場 | 動態性格 | 錨點起點 |
|---|---|---|---|---|---|
| 沉穩專業 | 90–108 | .3 → .7，緩升 | push、wipe、fade | 俐落、少彈跳 | corporate、minimal |
| 科技前衛 | 112–124 | .35 → .95 | push、zoom、glitch | 快進場、光暈 | tech、data |
| 溫暖親切 | 92–104 | .3 → .8 | iris、fade、push | 柔和、彈性 | warm、pastel |
| 質感人文 | 76–90 | .25 → .7 | fade、wipe | 慢、留白多 | editorial、ink、minimal |
| 活潑衝擊 | 124–138 | .5 → 1，跳躍 | cut、flash、push | 硬切、逐拍 | brutalist、neon |
| 數據理性 | 100–112 | .35 → .85 | push、fade | 生長動畫、等寬數字 | data、corporate |

**風格一律生成，不讓使用者從清單挑**：選最接近的錨點，再依情境覆寫 colors、fonts、music.bpm、background（格式見 `styles/_schema.json`）。提案時寫出**跟錨點的差異點**，避免每支片都長一樣。使用者點名某個內建風格時照做即可，但不要主動列出清單。

品牌色：主色放 a1、輔色 a2／a3，依品牌底色決定亮暗錨點。style_gen 會自動修正對比不足的顏色，**有修正時要在提案或交付時告訴使用者**（品牌色被調過）。

## 5. 觀眾 → 可讀性

| 觀眾 | 每幕最多項目 | 字級 | 每項最少停留 |
|---|---|---|---|
| 手機滑動（社群） | 3 | 直式 h1 以上當主視覺 | 1 拍 |
| 會議、簡報 | 4 | body 以上 | 1 拍 |
| 大螢幕 | 4 | h3 以上 | 1–2 拍 |
| 年長或非專業觀眾 | 3 | body 以上，不用 tiny | 2 拍 |

## 5-2. 情境 → 畫風（有插畫或場景畫面時，詳見 looks.md）

| 情緒／場合 | 建議畫風 | 次選 |
|---|---|---|
| 溫暖、療癒、品牌故事 | water 水彩 | paper 剪紙 |
| 東方文化、節慶、典故 | ink 水墨 | paper 剪紙 |
| 產品介紹、說明、商業簡報 | flat 扁平插畫 | poly 低多邊形 |
| 情緒短片、故事開場、MV | anime 動畫風背景 | water 水彩 |
| 活動宣傳、社群短影音、衝擊感 | comic 美漫網點 | neon 霓虹 |
| 尾牙、潮流、科技活動 | neon 霓虹合成波 | pixel 像素 |
| 電玩、復古、遊戲化 | pixel 像素 | neon 霓虹 |
| 兒童、教育、手作感 | crayon 蠟筆 | paper 剪紙 |
| 科技感風景、資料背景 | poly 低多邊形 | flat 扁平 |

構圖不從這張表推：主體、場景、遠近與動態要**開放問使用者**（SKILL.md「推斷情境、補問素材與構圖」），使用者沒想法時再依素材提一個構圖讓他改。

## 6. 畫面選擇：零件或自訂

- 這幕的內容是「標題／卡片／步驟／時間軸／數字／圖表／對比／條列／逐拍大字／倒數／字標／行動呼籲」其中之一 → 用對應的 `L_` 零件（欄位見 library.md），最快、橫直式都驗證過。
- 這幕的重點是某個**具體的畫面隱喻**（產品介面、流程動畫、品牌圖形、物件變形）→ 寫自訂場景。不要為了遷就零件而把內容改成條列。
- 一支片通常 60–80% 用零件、1–2 幕自訂，就能兼顧速度與獨特性。

## 7. 提案格式（一次給完）

```
**規格**：9:16、約 22 秒、有配樂（因為要放 IG Reels）
**構圖**：（使用者描述的主體與場景；或「我想到的是……，你想怎麼安排？」）
**畫風**：水彩（溫暖、療癒，符合新人歡迎的情緒；次選剪紙）
**風格**：溫暖、可信任——米白紙感、深綠主色、襯線標題、92 BPM 柔和鋼琴（以 minimal 為起點，改成紙紋背景與綠色系）
**分鏡**：（storyboard.py --preview 的表格）
OK 就開工，或告訴我要改哪裡。
```

短片（15 秒內）或使用者說「直接做」「你決定」時跳過確認：構圖用你依素材建議的構圖，交付時寫明採用了哪個構圖與哪些推斷。

**素材太多、超過平台片長時**：先刪寫不出 say 的幕 → 合併相近的幕 → 還是太長就在提案裡寫「這支 N 秒＋建議拆成第二支」。各平台上限：Reels／Shorts 30 秒內最有效（上限 60 秒）、GIF 20 秒內、簡報開場 40 秒內、活動大螢幕 60 秒內。
