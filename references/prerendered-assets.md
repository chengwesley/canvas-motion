# 預先算圖：像素風、場景地圖、精細角色

需要插畫質感的片子（像素風、俯視角場景地圖、有細節的角色與道具），每格用 Canvas 程式現畫很難畫到位，也慢（實測每格 25–48ms）。改成「畫面先算成圖檔，影片裡只貼圖與移動」，質感可以直接做到樣張的水準，每格約 6ms。這份是做過一支像素風講解片後的筆記，是一種有效做法，不是規定。

## 1. 做法

```
<專案>/
├── art/lib.py        繪圖庫：畫布、色階、抖色、描邊、各元件的繪製函式（可 import，沒有副作用）
├── art/make_all.py   把所有元件與背景輸出成 PNG
├── assets/*.png      原生像素尺寸、透明底（背景地圖不透明）；build 會內嵌成 data URI
└── scenes/00_*.js    貼圖與鏡頭的共用函式；各幕只負責移動、切換狀態、疊文字
```

- **樣張與成片用同一套繪圖程式**：給使用者確認的元件稿就是 `art/lib.py` 畫的，確認後直接輸出成素材，不會有「樣張好看、成片走樣」。
- **素材用原生像素尺寸**（1 個美術像素＝1px）、透明底。影片裡用整數倍放大，關掉平滑（`ctx.imageSmoothingEnabled = false`），邊緣才銳利。
- **定一個美術格**：例如 4:5 畫面是 180×225 美術像素，單位 `U = W / 180`（1080 寬時是 6）。座標都用美術像素寫，貼圖位置對齊到 `U`。
- **背景一張大地圖、全片共用**：例如 360×450，各幕把鏡頭移到不同地標。地標座標定成常數，各幕與繪圖程式共用同一份。
- **會動的東西是獨立素材**：角色每個狀態 2 格（呼吸）、行走 4 格；旋轉的東西 3–4 格。角色與道具一拍兩格地動，鏡頭平移與推近保持平順。
- **小粒子與光效**直接在場景裡畫成 `U` 大小的方塊，不必做成素材。
- **中文字不用像素字型**：像素字型多半沒有中文字。中文用 `txt()` 維持清楚，像素字型只給數字與英文。

## 2. 讓像素圖有質感的三招

- **有序抖色**：用 Bayer 4×4 矩陣決定兩個顏色之間哪些像素取亮色，做出漸層與材質（草地、水深、陰影、光暈）。
- **色階**：每個顏色準備 3–4 階（陰影、主色、亮面、高光），光從左上來：左上邊取亮、右下邊取暗。
- **統一描邊**：所有物件用同一個深色描邊；地面陰影用同一組顏色的抖色。全片看起來才像同一個世界。

## 3. 注意

- **不要用非整數倍縮放**素材；需要小尺寸就另畫一份。
- **素材要自己原創**：可以參考某個年代或類型的整體感覺（配色明亮、粗描邊、俯視角），不能照畫既有作品的角色、圖樣、標誌或場景。使用者給的參考圖只用來對「水準與氣氛」。
- **建築、樹這類物件的陰影畫進素材**；會移動的小道具不帶陰影，由場景決定。
- 素材很小（50 個像素素材約 84KB），不用擔心發布大小上限。
- 多人同時製作時，把素材檔名、地標座標、貼圖函式簽名先寫成規格，見 `agents.md` 第 2.5 節。
