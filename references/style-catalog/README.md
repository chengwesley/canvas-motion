# 風格目錄

做插畫感的知識影片前，先從這裡挑風格，再給使用者看樣張確認。每種風格一個資料夾：

- `sample.png`：同一個題目的樣張（AI 助理把筆記卡放進知識庫，旁邊一個大數字 61%），方便互相比較
- `sample.py`：產生樣張的程式（Python＋PIL），也是這個風格的畫法起點
- `style.md`：風格指引（指標畫法、代表畫家與作品、配色色階、光影、線條、質感、比例、字體、動態、元件清單、常見失敗、原創界線）

總覽圖：`overview_done.png`（已有完整指引的風格）、`overview.png`（全部 20 種，含只有樣張的）。重新產生：`python3 make_overview.py --done`、`python3 make_overview.py`。

## 補一種風格時

照已完成的 `style.md` 的段落格式寫，色碼要跟 `sample.py` 一致。中文字只用 STHeiti Medium 或 Hiragino Sans GB，其他字型常缺繁體字。代表畫家與作品只列有把握的，不確定的在該行標「（待查證）」。主角是機器人或機械形體，不畫有眼睛嘴巴的卡通臉。

## 要再畫得更好（下一步）

目前的樣張每張只看過一次。要往上提升，依效果排序：

1. **跟真的好作品並排比**：找幾張代表畫家或公開館藏的參考作品，讓代理把樣張跟它們並排看再修。參考圖只拿來對照，不存進 skill。
2. **每種修三輪，每輪只盯一件事**：第一輪構圖與主角辨識度、第二輪質感與配色、第三輪細節與文字。
3. **把共通畫法做成共用工具**：網點、紙紋、抖色、刷痕、墨暈、手繪抖線，放進共用模組，各風格直接呼叫，不要每種從零寫。
4. **先畫元件表再組場景**：每種風格先畫機器人、筆記卡、書櫃、數字牌等元件，再拼成樣張（像素科技城市就是這樣做出來的）。
5. **靠手感的風格用圖像生成模型補**：水彩、水墨、黏土、粉筆用程式畫天花板很低，可以生成底圖或材質，再用程式統一配色與排版；風格一致性與授權要另外把關。
6. **給使用者挑**：每種畫兩三個變化版本並排，讓使用者選方向再修。

建議先挑最常用的 2–3 種照 1、2、4 做精，方法驗證有效後再套到其他種。

## 注意

- 已有完整指引的 10 份，「代表畫家與作品」已上網查證過（紀錄見 `VERIFY_LOG_A.md`、`VERIFY_LOG_B.md`）；少數生卒年仍是依知識填寫，紀錄中有註明。
- 參考畫家只用來學技法，不照畫他們的構圖、角色或招牌圖樣。
